## 三、⚠ 这一轮是 HTTP，不是 HTTPS —— 有两件事要先知道

上一轮 POC 是 `https://poc.hqtw.cn/`，**这一轮只能走 HTTP + 裸 IP**。原因不是偷懒：

- 自有域名**没备案**，阿里云在网络层按域名拦，**HTTP 和 HTTPS 都拦**，连证书都签不下来（签发要走同一条被拦的路）；
- 裸 IP：**公共 CA 不给 IP 签证书**。

所以 HTTP + 裸 IP + 独立端口是**唯一可行**的形态。由此带来两件事：

**① 微信可能在页面顶上挂一条「非官方网页」之类的提示条。**
这是微信对 HTTP 页面的常规提示，**不影响功能**，不是页面出错了，忽略即可。

**② 如果 iOS 上出现意外表现，先别急着下结论。**
复核过：这四项（加密播放 / 凭证签发 / 水印+全屏 / 禁前跳）**都不依赖安全上下文**——
`MediaSource`、`Fullscreen API` 都不要求 HTTPS。**但那是判断，不是实测。**

> **所以：iOS 上一旦有异常，先换一个 HTTPS 环境复现一次再下结论，
> 不要当场判定「iOS 不行」。** 免得把 HTTP 的锅记到 iOS 头上。
